# Vehicle Attribute Recognition

A computer vision project for vehicle detection, tracking, and attribute recognition.

## Features

- Vehicle detection and tracking
- Vehicle type classification
- Vehicle color recognition
- Vehicle make recognition

## Datasets

- MIO-TCD – Vehicle Type Classification
- Vehicle Color Dataset – Vehicle Color Recognition
- Riotu Cars Dataset – Vehicle Make Recognition
